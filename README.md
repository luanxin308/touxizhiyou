# 透析之友 · touxizhiyou

给透析病人自己用的离线小工具：**称体重、拍血压计、算本次排水、记开药花费**。
全程不联网、不注册、不上传，数据只存在手机本地。

> 面向老年使用者设计：字大、按钮大、颜色对比强、关键数字一眼可见。
> 本应用只做记录与提醒，**不提供诊断，实际脱水量与用药以医生处方为准**。

**仓库地址** → https://github.com/luanxin308/touxizhiyou
**安装包下载** → [Releases · v1.0](https://github.com/luanxin308/touxizhiyou/releases/download/v1.0/touxizhiyou-v1.0.apk)（约 57 KB，安卓 7.0 及以上）

## 一、它能做什么

### 1. 体重与本次透析量
透析病人两次透析之间会长水，上机前比上次下机重多少，这次就要脱多少水。

```
本次排水量 ΔW = 本次上机体重 − 上次下机体重
```

- 每次上机前记「上机体重」，下机后再记「下机体重」
- 记录上机体重时，应用自动找出上一次的下机体重，当场算出**本次预计排水**
- 历史条目 + 双折线趋势图（上机体重、下机体重、两点间虚线＝本次排水）
- 平均 / 最多 / 最少排水量统计
- 异常提示：ΔW < 0（比上次下机还轻）、> 5 kg、与上次间隔 > 7 天，都会提醒核对

### 2. 血压与心率
- 上机时、下机时**分别记录**高压 / 低压 / 心率
- 点任意一行弹出大键盘填写，不用在小格子里戳
- 按收缩压/舒张压自动分级（偏低 / 正常 / 偏高 / 很高），心率过快过慢也会提示
- 历史列表按时间倒序，首页显示最近一次

### 3. 拍照识别数码管
- 调用手机相机拍体重秤 / 血压计，离线识别屏幕上的数字
- 识别页有取景框和对位提示（离数字 20–40 cm，手机拿稳）
- 识别完进入**逐位确认页**：每一位都能点开改，确认无误再记入
- 也支持从相册选已有照片；实在识别不出可以手动输入

### 4. 开药助手
- 内置透析/肾病常用药品库（磷结合剂、活性维生素 D、铁剂、促红素、降尿酸、纠酸、营养等 18 种），可自行增删改
- 每个月生成一张处方：选药 → 填每次几片 × 每日几次 × 共几天
- 每月记录**药费**与**透析费**两项总额（不记单盒单价，老年人买药只看总账）
- 支持「复制上月」，下个月在此基础上微调
- 花费统计：按月 / 按季 / 按年 / 全部，柱状图 + 药费与透析费构成占比

### 5. 适老化
- 正文 20px 起，三档字号可调（标准 / 大 / 特大），全局等比放大
- 主按钮 68px 高、圆角 18px，数字键盘按键 67px
- 关键数字 62–72px，暖米黄底 + 橙色重点，对比度 ≥ 7:1
- 底部导航只有 5 个入口，中间的相机键凸起方便按

## 二、安装

1. 下载 `dist/touxizhiyou-v1.0.apk`
2. 传到安卓手机（微信文件传输助手、数据线、U 盘都行）
3. 手机上点开安装，若提示「未知来源」，在设置里允许本次安装即可
4. 支持 Android 7.0（API 24）及以上

首次打开是空数据，可以进「设置 → 填充示例数据」看看效果，再「清空所有数据」开始正式记录。

## 三、识别原理（为什么不用现成 OCR）

通用 OCR（ML Kit / Tesseract）对**七段数码管**识别率很低：数码管的 `1` 是两根竖线、`0` 中间有一道斜杠、`8` 是七段全亮，这些在通用 OCR 的字形模型里没有对应训练样本。GitHub 上能找到的七段识别项目（如 OCR7SD、segment-display-ocr）全是桌面 Python/OpenCV 实现，没有能直接嵌进安卓离线 APK 的成熟库。

所以本项目内置了一个**零依赖的轻量识别引擎**（`app/assets/js/ocr.js`，纯 JavaScript，跑在 WebView 里）：

1. 灰度化（BT.601 加权）
2. Otsu 大津法自适应二值化，并自动判断极性（暗底亮字 / 亮底暗字）
3. 水平膨胀把同一个数字的七段粘连成一个连通块
4. 行投影找出数字所在的行带（并用段带高度中位数区分"数字内部的段缝"和"两行之间的空行"），列投影切出每一位
5. 按七段位置（a/b/c/d/e/f/g）相对坐标采样每段亮灭，得到 7 位掩码
6. 查表映射到 0–9，允许 1 位汉明距离容错（如 6/8 边缘模糊时）
7. 小数点按"高度不到行高 45%"单独判定，数字 `1` 按"宽高比 < 0.36"单独判定——这两条是避免 `1` 被当成小数点、小数点被丢掉的关键

### 识别自测

`app/assets/ocr-test.html` 用 canvas 按真实七段坐标画出各种数字（黑底绿字 / 亮底黑字、字号 40–96 px、带模糊、带噪声、三行血压计），逐个跑识别并打印通过率。当前用例 **17/17 全部通过，三行血压计（152 / 88 / 76）也正确分成三行**。

同一个页面里如果出现 `?`，说明该位掩码对不上任何数字（多半是反光或角度太斜），确认页会让您手改。

### 最后一道保险

识别结果永远要人点一下「确认记入」才落库；确认页每一位都能点开改，血压场景三行都能单独改。

`app/assets/test.html` 与 `app/assets/shot.html` 是开发自测页，构建时会自动从 APK 中剔除。

## 四、项目结构

```
touxizhiyou/
├─ android/                     Android 原生壳（Java，无第三方依赖）
│  ├─ AndroidManifest.xml
│  ├─ res/                      图标、字符串、主题
│  └─ src/com/touxizhiyou/app/
│     └─ MainActivity.java      WebView 壳 + 相机 Intent + JS 桥
├─ app/assets/                  前端（离线，file:// 加载）
│  ├─ index.html
│  ├─ css/app.css               设计系统（暖米黄 + 橙，适老字号）
│  ├─ js/util.js                格式化、血压分级、弹层、键盘
│  ├─ js/store.js               localStorage 数据层 + 18 种预置药品
│  ├─ js/ocr.js                 七段数码管识别引擎
│  ├─ js/pages1.js              首页 / 体重 / 趋势 / 血压
│  ├─ js/pages2.js              相机 / 确认
│  ├─ js/pages3.js              开药 / 药品库 / 花费统计 / 设置
│  ├─ js/app.js                 hash 路由 + 原生回调
│  ├─ test.html                 开发自测页（不进 APK）
│  └─ shot.html                 截图用容器页（不进 APK）
├─ docs/01-产品与功能规划.md     产品规划、业务公式、数据模型、里程碑
├─ proto/effect.html            高保真效果图（8 屏，浏览器直接打开）
├─ proto/shots/                 效果图与真机版式截图
├─ tools/build.ps1              离线构建 APK（aapt2 + javac + d8 + apksigner）
├─ tools/shots.ps1              批量截图脚本（Edge headless）
└─ dist/touxizhiyou-v1.0.apk    可直接安装的安装包
```

### 技术选型说明

- **原生 Java 壳 + WebView 前端**：不引 AndroidX / Gradle / Kotlin，全部依赖都用系统自带的 `android.jar`，因此可以在一台没装 Android Studio 的 Windows 机器上用 SDK build-tools 直接命令行构建，APK 只有 53 KB。
- **存储用 localStorage + JSON**：单病人、数据量小（一年约 150 条记录），不引数据库。
- **图标与图表全部自绘**：SVG 内联、Canvas 手画折线柱状图，零图片资源。
- 前端只使用 ES5 兼容语法，保证 Android 7.0 的老 WebView 也能跑。

## 五、自己构建

环境要求：

- JDK 17（本机路径示例：`C:\Program Files\Microsoft\jdk-17.0.18.8-hotspot`）
- Android SDK，含 `build-tools/35.0.0`、`platforms/android-34`、`platform-tools`

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

脚本会：把工程镜像到 `C:\tb`（aapt2 不支持中文路径）→ `aapt2 compile` 编译资源 → `aapt2 link` 打出带 assets 的 base.apk → `javac` 编译 Java → `d8` 生成 dex → 塞进 apk → `zipalign` 对齐 → `apksigner` 用自签证书签名，产物输出到 `dist/`。

安装到手机：

```powershell
adb install -r dist\touxizhiyou-v1.0.apk
```

## 六、数据与隐私

- 所有数据保存在手机本地 `localStorage`（键 `touxizhiyou.db.v1`）
- 应用**不申请联网权限**，没有服务器、没有账号、没有埋点
- 卸载应用或「设置 → 清空所有数据」会删除全部记录，请自行用「导出备份」定期存一份
- 相机权限仅用于拍秤和血压计，照片不会离开手机
